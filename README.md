# Dh 4

Интерпретируемый язык программирования с динамической типизацией.

## Возможности:
* Назначение переменных(int, str, bool, значения других переменных)
* Вывод в консоль(различные типы, в том числе переменные. без перечислений)

## Базовый синтаксис:
Назначение переменной (ключевое слово ``var``)
```
var NAME = "variable value"
var NAME2 = 321231
var NAME3 = false

var NAME2_CLONE = NAME2
```
Вывод в консоль (ключевое слово ``print``)
```
print "текст"
print NAME
print 3213
```

## Внутреннее устройство

Используется объектная система. Есть абстрактный класс DhObject, от которого наследуются DhInt, DhString, DhBool и т.д.

Для чтения файла используется класс Reader. Предполагает управление частями программы для быстрых переходов на другие строки и автоматическим возвращением на прошлые части.


После чтения линии(простого текста) Reader-ом, она отправляется в лексер. Программа читает файл построчно, и каждая строка обрабатывается лексером отдельно.\
Позже, после получения списка токенов на линию, этот список отправляется в парсер. Там уже он определяет, какой Statement вернуть и определяет выражения(Expression)\
Возвращает Statement(имеет метод execute), который позже сам интерпретатор и исполняет(передавая ссылку на себя для передачи окружения и т.д.).

Для хранения объектов используется класс Environment. Имеет HashMap<ключ, DhObject> в котором хранятся переменные в рантайме.
